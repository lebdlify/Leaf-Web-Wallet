Guide

Comfortable wallet flow for desktop and phone.

Save your API key once. After login, the API card is hidden and can be reopened from the header.

Add accounts in the compact account dropdown. The list stays hidden by default when you already have an active account.

Use Browse account to inspect balances, loans and debts of any user. Update all refreshes the three sections with one click.

Optional fields such as max fee in send or token in get balance are omitted automatically when left empty.
